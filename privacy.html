Privacy Policy

Last updated: 23 November 2026

1. Who we are

Stickman Studio Publisher ("the tool") is a private, single-user tool run by an independent Czech video creator ("the owner") to manage the owner's own YouTube channels. Contact: nexuscz150@gmail.com.

2. Use of YouTube API Services

The tool uses YouTube API Services (YouTube Data API v3 and YouTube Analytics API). By using the tool you agree to the YouTube Terms of Service. Google's processing of data is governed by the Google Privacy Policy (http://www.google.com/policies/privacy).

3. What data the tool accesses

  • Basic information about the signed-in channel (channel name, ID, subscriber count).
  • The channel's own videos, playlists and their metadata (titles, descriptions, tags, privacy status, publish times, public statistics).
  • The channel's own YouTube Analytics reports (views, watch time, audience retention, traffic sources, aggregated audience demographics).
  • Public comments on the channel's own videos (read only).
  • Public metadata and statistics of other public videos and channels, for topic research.

The tool does not access private data of any other YouTube user and does not collect personal data from viewers.

4. How the data is used

Only to upload and manage the owner's videos and to help the owner decide what videos to make. Data is never sold, shared with third parties or used for advertising.

5. Storage and retention

OAuth access tokens are stored only on the owner's own computer and are never transmitted anywhere except to Google. API data is processed in memory or kept in local working files of the owner; it is refreshed or deleted within 30 days. Nothing is stored on any server.

6. Cookies

The tool and this website do not use cookies or tracking.

7. Revoking access

Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions. After revocation, locally stored tokens stop working and are deleted within 7 days.

8. Changes

Changes to this policy will be published on this page with a new "Last updated" date.
